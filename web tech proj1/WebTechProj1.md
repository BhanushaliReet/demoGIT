# CSS Mini Project - Thala 7 Sneaker Store

## Project Overview
A complete e-commerce single-page interface for the **Thala 7 Sneaker Store** featuring four key customer journeys implemented without external frameworks like Bootstrap.

## Sections Implemented
1. **Landing Page**: 
   - Flexbox Navbar with Logo, centered menu links, search, cart, and profile icon.
   - Hero split section with headline, "Shop Now" call to action, and highlighted shoe presentation.
   - Service overview ribbon highlighting 2k+ reviews, 30k+ customers, High Quality, and 4.5/5 rating.
2. **Product Display**:
   - Product view containing high-resolution image, descriptive specs, tiered price badge, quantity picker, and "Add to Cart" action.
   - Bottom horizontal scrolling gallery holding multiple thumbnail views.
3. **Shopping Cart**:
   - Tabular layout itemizing added products, quantity pills, prices, and removal action.
   - Descriptive order breakdown side-panel with coupon input and calculated total.
   - "Continue Shopping" navigation link.
4. **Payment / Checkout**:
   - Two-column split checkout containing email input and tabbed payment selection (Cards, Crypto, Bank).
   - Card information input fields (Card Number, Expiry, CVC, Country, ZIP code).
   - Order summary verification card with Pay Now button and Razorpay validation.
