# Laundry Services - Button Interactive (Transforms)

## Overview
Added interactive CSS hover effects to the primary call-to-action (CTA) button in the Laundry Services Hero Section.

## Features Implemented
- **Hover Scale**: Utilized CSS `transform: scale(1.1)` to increase the button size smoothly on hover.
- **Hover Tilt**: Applied `transform: rotate(-6deg)` to create a tilted interactive animation.
- **Transitions**: Added `transition: transform 0.3s ease, box-shadow 0.3s ease` for natural animation timing.
- **External Files**: Fully linked `index.html`, `style.css`, and `script.js`.
