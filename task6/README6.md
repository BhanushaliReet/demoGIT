# demoGIT# CSS - Laundry Mart Login Page

## Description
A modern, responsive login page for Laundry Mart designed using a 50/50 split layout.

## Features & Implementation
- **Flexbox Alignment**: Centering and column alignments are handled using Flexbox (`display: flex`, `justify-content: center`, `align-items: center`).
- **Full Viewport**: Container is set to `100vh` without scrollbars.
- **Pure CSS**: Created without frameworks (e.g., no Bootstrap).
- **Files Included**: `index.html`, `index.css`, and `Readme.md`.
