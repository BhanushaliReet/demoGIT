# JavaScript - Odd or Even Checker

## Description
A JavaScript program that checks whether given numbers are odd or even using `if-else` conditional statements and the modulus operator `%`.

## Implementation Details
- Declared four numeric variables (`num1`, `num2`, `num3`, `num4`).
- Used conditional `if (number % 2 === 0)` to check for evenness.
- Outputs status messages to the browser console using `console.log()`.
