# Responsive Laundry Services Web App

## Overview
A responsive hero section and navigation bar for a laundry service application built using HTML5, CSS3, Flexbox, and Media Queries.

## Implemented Responsive Features
- **Flexbox Navbar**: Built using `display: flex` and `justify-content: space-between`.
- **Tablet Optimization (`max-width: 900px`)**: Font sizes of logo, nav items, headings, and image dimensions scaled down proportionally.
- **Mobile Optimization (`max-width: 600px`)**:
  - Center navigation links hidden (`display: none`).
  - Top bar shows only Logo and Username.
  - Hero layout set to `flex-direction: column` with centered text and CTA button above the illustration.
