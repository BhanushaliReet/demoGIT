# JavaScript Compound Interest Calculation

## Description
A JavaScript program that calculates compound interest using static values based on the mathematical formula:
`A = P(1 + (r / n))^(n * t)`

## Variables Used
- `P`: Principal amount
- `r`: Annual interest rate
- `n`: Number of times interest is compounded per year
- `t`: Time in years
- `A`: Total accrued amount
- `compoundInterest`: Calculated interest (`A - P`)

## Output
The result is printed to the browser developer console via `console.log()`.
