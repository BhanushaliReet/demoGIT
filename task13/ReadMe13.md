# Loops in Programming - JavaScript Assignment

## Overview
A JavaScript application demonstrating loop and conditional control structures (`for`, `while`, `if-else`) to perform mathematical operations on numbers.

## Features Implemented
1. **Sum of First N Numbers**: Uses a `for` loop to accumulate values from 1 to N.
2. **Multiplication Table**: Loops from 1 to 10 to display the table of variable `n`.
3. **Digit Sum**: Uses a `while` loop with modulo (`% 10`) and division (`Math.floor`) to sum digits.
4. **Armstrong Number Check**: Verifies if the sum of digits raised to the power of 3 equals the original number.
5. **Prime Check**: Uses a `for` loop up to `Math.sqrt(num)` to test for divisors.
6. **Factor Extraction**: Identifies and logs all positive divisors of the number.
7. **Multiple Test Variables**: Evaluates more than 5 distinct variables (`nSum`, `nTable`, `numCheck1`, `numCheck2`, `numCheck3`).
